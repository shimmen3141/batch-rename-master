# 手動確認: 連番のゼロ埋めの切り替えと桁数の下限(下書き)

**下書きである。** ボタン名・文言・対象commitは実装後にcurrent revisionと照合して完成させる。

## 人間が観測する目的

- 連番のエディタでゼロ埋めの有無を切り替えられ、ゼロ埋めなしでは一覧の変更後名が数字そのまま(`1`〜`10`)で、警告が出ない。
- ゼロ埋めでは、件数と開始番号から決まる桁数より小さい桁数を選べない(例: 20件・開始90 → 3桁未満を選べない)。
- 件数を増やした後に桁が足りなくなると、該当する行に桁不足の警告が出る。連番を開くと直せる。

## 環境とfixture(実現可能性)

- Androidエミュレータ(`008:T39`の方針)。共通手順は[`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md)。
- 20件程度のファイルが要る。`adb`で`Download`配下へ作るcommandを実装後に書く。
