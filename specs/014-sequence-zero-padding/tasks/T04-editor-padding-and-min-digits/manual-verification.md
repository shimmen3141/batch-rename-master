# 手動確認: 連番のゼロ埋めの切り替えと桁数の下限(Androidエミュレータ)

**対象buildは、`lib/`・`hook/`・`src/`の内容が task.md の「Evidence revision」に書いた code commit と同一のもの**である。branch `asdd/014-sequence-zero-padding/T04-editor-padding-and-min-digits` のHEADからbuildすればこれを満たす。**code・dependency・build設定が変わったら、この結果は再利用しない。**

**Androidエミュレータで確認する**(`008:T39`で開発者が決めた方針)。見た目と操作を見るので debug build でよい。

## 使う端末と準備

- host側でworktree `.worktrees/014-T04-editor-padding-and-min-digits` へ`cd`してから`flutter pub get` → `flutter run`する(branchの移動は不要)。共通の手順は[`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md)。
- ファイルは`008:T25`のfixture(`Download/asdd-008-t25`の3件。改名後の名前でもよい)を使う。**無ければ**、[`008:T25`の手順書](../../../008-ui-alignment/tasks/T25-dismissible-toast/manual-verification.md)の「準備するファイル」を実行する。
- 「ファイルを選ぶ」→「すべて」→ `Download` → `asdd-008-t25` で3件を選んで確定する(一覧が3件になる)。
- 下の「**命名ルール**」のボタンを押してルールのシートを開き、今あるトークンは×で消して空にしておく。

## 1. ゼロ埋めなし

1. 「**＋ 連番**」を押す。
   - エディタに「開始番号」「**ゼロ埋め**」(スイッチ)「桁数」「増分」が並ぶ。ゼロ埋めは**ON(緑)**、桁数は**2**。
2. ゼロ埋めのスイッチを押して**OFF(グレー)**にする。
   - 「**桁数**」の欄が**消える**。スイッチの下の例が「例: 1, 2 … 10」になる。
3. 「追加」を押す。
   - シートのトークンが「**連番(ゼロ埋めなし)**」と出る。
   - シートを閉じると、一覧の変更後名が `1` `2` `3`(拡張子つき)で、ゼロ埋めされていない。行に警告は出ない。下の「命名ルール」の字面は `[1…]`。

## 2. ゼロ埋めの桁数の下限(3件・増分を上げる)

1. シートを開き、「連番(ゼロ埋めなし)」を押して開く。ゼロ埋めを**ON**に戻す。
   - 桁数の欄が戻り、**2**(保持していた値)。
2. 桁数の「−」を押して **1** にする(3件・開始1・増分1なので最大は 3 で、1桁にできる)。
3. 増分の「＋」を押して **5** まで上げる(4回)。
   - 増分が **5** になった時点で(最大は 1 + 2×5 = 11)、桁数が**自動で2**になる。桁数の「−」は**押せない**(グレー)。
   - 桁数の下に「**3件・開始1・増分5なので2桁以上**」と出る。
4. 増分の「−」を押して **4** に戻す(最大は 9)。
   - 桁数は**2のまま**(自動では下がらない)。桁数の「−」が押せるようになる。
5. 増分を **5** に戻して「確定」を押す。
   - 一覧の変更後名が `01` `06` `11`。行に警告は出ない。

## 3. 件数が後から増えたとき(ルールは書き換えない)

1. 連番を開き、増分を **1** に戻してから、開始番号を「＋」で **8** にする(7回)。
   - 3件・開始8なので最大は 10 で、**桁数は2より下げられない**(「3件・開始8なので2桁以上」)。ここでは下限が効いていることだけ見て「キャンセル」する。
2. 一覧の右上の︙ →「外すファイルを選ぶ」で1件を選び、「1件を外す」(一覧が2件になる)。
3. 連番を開き、増分を **1**、開始番号を **8**、桁数を **1** にして「確定」(2件なので最大は 9 で、1桁にできる)。
   - 変更後名は `8` `9`。
4. 「ファイルを選ぶ」から、同じ3件を選び直す(一覧が3件になる)。
   - **ルールは1桁のまま**(命名ルールの字面は `[8…]`)。**3件目の行に桁不足の警告**が出る(変更後名は `10`)。
5. 連番を開く。
   - 桁数が**2**で開く(下限まで上げた値)。「キャンセル」で閉じると、ルールは**1桁のまま**で警告も残る。
6. もう一度開いて「確定」する。
   - 変更後名が `08` `09` `10` になり、警告が消える。

## 4. 保存と復元(`014:T03`)

1. 連番をゼロ埋め**OFF**にして確定し、アプリを終了して起動し直す(`flutter run`で `q` → もう一度`flutter run`)。
   - 起動後のルールのシートで「**連番(ゼロ埋めなし)**」のまま。
