- 002 REQ-015・005 代表例20c/20c′: 桁不足の対象の導出(「指定桁数を超えて描かれる item」)。ゼロ埋めなしで桁不足を返さないなら文言の確認だけで済むはず — 確かめる。

## 決めること(spec差分の前に、要るものだけ開発者へ一問ずつ確かめる)

1. **ゼロ埋めなしの連番の`digits`**: 保持して評価で使わない / 持たない。エディタで桁数の欄を隠すか。
2. **下限の「件数」**: 一覧の件数(= rename対象。008:T03以後は一覧全件)でよいか。件数0のときの下限(開始番号の桁数)。
3. **件数が増えた後にエディタを開いたとき**: 桁数の欄を下限へ引き上げた値で開く / 今の値のまま開いて下限未満なら確定できない。
4. **保存の互換**: ゼロ埋めの項目を**任意**にし(無ければゼロ埋めあり)、版を上げない形で足りるか。版を上げると007 REQ-004により既存の保存が復元されずルールが消える。
5. **追加の初期値**: ゼロ埋めあり・2桁のままか。追加のエディタでも下限を適用するか。
