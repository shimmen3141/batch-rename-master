# 手動確認: SD カード・USB が保存場所に並ぶこと

**この手順書は `T12` の実装後に completed させる。** 現時点では観測する対象と、
使い回せるものだけを置く。

## 使い回せるもの

**`T08` の probe がそのまま使える。**
[`specs/013-safe-android-rename/tasks/T08-verify-device-coverage/manual-verification.md`](../T08-verify-device-coverage/manual-verification.md)
の手順1(権限)と手順2(観測)を実行すると、出力の先頭に
`--- app から見た /storage ---` が出る。**ここへ書き写さない。**

**ただし `T12` は列挙の手段を差し替えるので、probe 側も同じ手段を見るように直す必要が
ある**(現在の `storageViewOf` は `/storage` の中身を見ている)。実装時に決めること。

## 観測する対象(実装後に手順へ具体化する)

- **SD カードを挿した端末で、保存場所が2つ並ぶ**(004 代表例26e)。
- SD カードの root より上位へ辿れない(REQ-015)。**`T07` の manual 手順1と同じ**。
- **列挙に失敗したときに、利用者から見て「媒体が無い」と区別できる**(このtaskで決めた形)。
- 抜き差ししたあとに browser を開き直すと、並びが変わる。

## 環境の前提

`T08` の観測(2026-08-26)によれば、`sdk_gphone16k_x86_64` の emulator には
**仮想 SD カード(vfat)が装着されている**。したがって**この emulator で確認できる**
見込みである。実機は別途。
