## 事前準備

起動手順は [`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md) に従う。

- **branchを確認する。** `git branch --show-current` が
  `asdd/013-safe-android-rename/T06-implement-permission-flow`(または merge 済みなら `dev`)。
- **Android 11(API 30)以上の端末 / エミュレータ**を使う。`MANAGE_EXTERNAL_STORAGE`
  はAPI 30で入った権限で、それ未満の端末には**存在しない**。
- 設定画面で探すときのアプリ名は **`batch_rename_master`**(`AndroidManifest.xml` の
  `android:label`)。アプリ内のAppBarは「一括リネーム」、Recentsは「一括リネーム(デモ)」で、
  **3つとも別物**である。
- 各stepの先頭で、端末の「設定」→「アプリ」→`batch_rename_master`→
  「すべてのファイルへのアクセス」を**オフに戻してから**始める。

## 1. 未許可の状態で読み込もうとする(REQ-001 / REQ-002)

1. 権限をオフにした状態でアプリを起動する。
2. **起動直後**の画面を見る。
3. 「ファイルを選ぶ」を押す。

**期待**

- 起動しただけでは**設定画面へ飛ばない**。説明も出ない(REQ-002)。
- 「ファイルを選ぶ」を押すと、**種類を選ぶシートが開かず**、画面上部に
  「ファイルの名前を安全に変更するには、端末の『すべてのファイルへのアクセス』が
  必要です。…」という説明と「設定を開いて許可する」ボタンが出る(REQ-001)。
- **勝手に設定画面へ飛ばない**(REQ-003)。

## 2. 設定画面へ行って許可し、戻る(REQ-003 / REQ-004)

1. 「設定を開いて許可する」を押す。
2. 開いた設定画面で、このアプリの「すべてのファイルへのアクセス」を**オンにする**。
3. 端末の戻る操作でアプリへ戻る。
4. 「ファイルを選ぶ」を押す。

**期待**

- 手順1で、**このアプリの**「すべてのファイルへのアクセス」の設定画面が開く
  (アプリ一覧ではなく、アプリ個別の画面が望ましい。一覧が開いた場合はそのまま
  アプリを探して続行し、**どちらが開いたかを報告する**)。
- 手順3で戻った直後、**説明が消えている**(REQ-004: 戻った時点で再確認している)。
- 手順4で種類シートが開き、ファイルを選べる。

## 3. 許可を取り消してから実行する(REQ-004 / INV-002)

1. 手順2の続きで、ファイルを数件読み込み、ルールを1つ以上置く。
2. **アプリを閉じずに**、端末の設定から「すべてのファイルへのアクセス」を**オフにする**。
3. アプリへ戻り、**実行**する。

**期待**

- 「『すべてのファイルへのアクセス』が許可されていないため、名前を変更できませんでした。…」
  というメッセージが出る。
- **ファイルの名前が1件も変わっていない**(INV-002)。端末のファイルアプリで確認する。
- 「ファイルを選ぶ」を押すと、また説明が出る(REQ-003: 黙らない)。

## 4. 拒否し続けたときの見え方(REQ-003)

1. 権限をオフにした状態で「ファイルを選ぶ」→ 説明が出る。
2. 「設定を開いて許可する」を押し、**許可せずに**戻る。
3. もう一度「ファイルを選ぶ」を押す。

**期待**

- 説明と「設定を開いて許可する」が**出たまま**である。消えない。
- 押すたびに設定画面へ飛ばされる、といった押し付けにはなっていない
  (飛ぶのはボタンを押したときだけ)。

## 5. 狭い画面での可読性

1. 権限をオフにして説明を出した状態で、**縦向きの狭い端末**(または画面分割)で見る。

**期待**

- 説明文が途中で切れず読める。「設定を開いて許可する」ボタンが押せる範囲にある。
- 説明が画面を占有しすぎて、下のリストや操作が使えなくなっていない。
