## 目的（説明的・正誤判定には使わない）

メイン画面のプレゼンテーション状態層 `FileListController` の振る舞いを定義する。ファイル一覧の保持・選択・ソート・カスタム順・ルール注入から、各行の「現在名／変更後名（001 のプレビュー）」を供給する。ウィジェットはこの状態を描画する薄い層で、視覚デザインは本仕様の対象外（後日の参考デザインですり合わせ）。

## 境界

- 対象（in scope）: `FileListController` の状態と操作、**リストの置き換え/除去/全消去**（004 が供給、操作は本コントローラ）、行データ（RowView 列。**場所サブ情報を含む**）の算出、ソート種別、カスタム順への自動切替。
- 対象外（out of scope）: 実ファイルの**取得元・権限**（004）・リネーム実行（005）・ルール構築UI（003）・エクスプローラ D&D（006）・視覚デザイン（レイアウト/配色/余白）。リストへ供給する `FileEntry` の生成は 004（本コントローラは受け取った `FileEntry` を保持・操作するのみ）。
- アクター: ユーザー操作（ウィジェット経由）、注入元（003 の `RenameRule`、004 の `FileEntry` 一覧）。
- 入力: `List<FileEntry>`、`RenameRule`（注入、既定は元名トークンのみ）、`now`。
- 出力: 行データ列（各行の現在名・変更後名・選択状態）、現在のソート種別。
- 永続化される状態: なし（画面内の表示状態のみ）。
- 外部副作用: なし（ファイル操作は行わない）。

## 振る舞い

### 状態変数

- `items`: 表示順の `FileEntry` 列（初期化と `setFiles` では現在の並び順を当てはめる。REQ-001 / REQ-008）。
- `selectedOf(item)`: 各 item の選択フラグ。
- `sortMode`: `name` / `createdAt` / `modifiedAt` / `size` / `custom`。**時系列は作成日時・更新日時の2種**を提供する（2026-08-04 開発者決定。旧「`createdAt` を `modifiedAt` へ置換」の方針を取り消し）。作成日時は取得できない場合があり（001 の `FileEntry`）、そのときの扱いは REQ-002 / REQ-011 が定める。**`custom` は選ぶものではなく、手で並べた結果を示す状態**である（REQ-003。2026-09-30 `008:T01`）。
- `sortDirection`: `ascending` / `descending`。`sortMode` が `custom` のときは意味を持たない（2026-09-30 `008:T01`）。
- `rule`: プレビューに用いる `RenameRule`（注入。既定は元名トークンのみ）。

### 操作（イベント）

| 操作 | 効果 |
|------|------|
| 初期化(files, rule) | `items` = 入力を**名前の昇順**で安定ソートした列、選択 = 全選択、`sortMode` = `name`、`sortDirection` = `ascending`、`rule` を保持 |
| `setSortMode(mode, direction)` | `items` を mode の comparator で direction の向きに安定ソートし、`sortMode` と `sortDirection` を更新する。**mode に `custom` は指定できない**（REQ-003） |
| `reorder(oldIndex,newIndex)` | `items` をその移動後の順に並べ替え、`sortMode` を `custom` へ自動切替 |
| `toggleSelection(item)` | その item の選択を反転 |
| `selectAll()` / `clearAll()` | 全 item を選択 / 全解除 |
| `setRule(rule)` | プレビューに使う `RenameRule` を差し替え |
| `setFiles(entries)` | 現在の `items` と選択を捨てて `entries` で**置き換え**、全件を選択状態にする。**蓄積しない**（004 REQ-004/005 由来。2026-08-05 に旧 `addFiles`（蓄積・重複排除・末尾追加）から変更）。**置き換えた列へ現在の並び順を当てはめる**。`sortMode` が `custom` なら名前の昇順へ戻す（REQ-008。2026-09-30 `008:T01`） |
| `removeFile(handle)` | 元場所ハンドルが `handle` に一致する item を `items` と選択から除去する。一致が無ければ無変化（004 REQ-006 由来） |
| `clearFiles()` | `items` と選択を空にする（004 REQ-006 由来） |

### 代表例

### 008 T27 由来の更新（2026-09-19・開発者再承認済み）

**行ごとの × を撤去し、除去は「長押しで入る一時的な選択モード」でまとめて行う**（REQ-018）。
`T03` で決めた REQ-016 は**通常表示に限定**する。実装は後続 task。

- **理由**: ×（除去）と並び替えのつまみが**行の右端で隣り合っており押し間違えうる**
  （2026-09-18 の実機確認と開発者の提案）。加えて、**部分的にまとめて外す手段が無い** —
  いまは 1 件ずつ × を押すか、帯の「一覧を空にする」で全部空にするしかない。
- **押し間違いは構造で消す。** 通常表示の行に除去操作を置かなければ、つまみと隣り合う相手が
  そもそも無くなる。× を左端へ動かして距離で緩和する案（案B）は、**まとめて外す不便が残る**ので採らない。
  × を残したまま選択モードを足す案（案C）は、**隣り合いが残るので主目的を達成しない**。
- **入口を 2 つ要求するのは代替導線のため。** 長押しは Flutter ではマウスでも発火するが、
