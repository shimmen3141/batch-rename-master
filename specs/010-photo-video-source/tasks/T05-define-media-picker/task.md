# T05 「画像」「動画」から選ぶ画面を仕様にする

## 目的

読み込みの種類「画像」「動画」(004 REQ-011 で**枠のみ**)を押したときに開く**選ぶ画面**を、004(と連動するなら 002)の仕様へ差分として書き、開発者の承認を得る。
実装の task は、この仕様が決まってから足す(plan.md の「対象外」にあった「アルバム・全件から選ぶ画面」をこの plan で扱う)。

## 入力と依存

- `T01`〜`T04`(作成日時。①中身 → ②`DATE_TAKEN` → ③`DATE_ADDED`)。folder をまたぐ一覧を撮影順に並べられる前提ができた。
- `008:T24` の申し送り(product-map の 010 の行): folder で行を束ねない。どの folder のファイルかは行の場所(002 REQ-010)で見分ける。
  **読み込み元(album・全件)を、一覧を選択済みにして開き直す入口**を設ける(1 folder の folder 行 = 004 REQ-021 はその特別な場合)。002 REQ-021 の並びの規則が読み込み元の単位でも成り立つかを確かめる。
- 004 REQ-011(種類)・REQ-004(確定は置き換え)・REQ-015〜021(app 内 browser)・REQ-013(所属 folder)。
- `010:T03` の端末観測: **adb で置いたファイルは、全ファイルアクセス権限でも MediaStore の照会に出ない**。カメラ・スクリーンショット・ダウンロードは出る。
  `010:T04`: この app が path で作ったファイルは MediaStore に載らない。改名しても MediaStore の行は新しい名前を追う。
- 改名は今も path で行う(013 の全ファイルアクセス権限)。

## 決めること

- **入口の形**: 「画像」「動画」で何が開くか(全件 / アルバム一覧 / 両方。最初にどれを見せるか)。
- **見せ方**: サムネイルの格子か行か、並び順(撮影日の新しい順など)、日付の区切りの有無。
- **選び方**: 1件ずつ、範囲(長押し drag)、全選択・まとめて解除(004 REQ-020 と揃えるか)。
- **確定の結果と開き直し**: 確定は REQ-004 の置き換えか。一覧から読み込み元(全件・アルバム)を選択済みで開き直す入口(`008:T24` の申し送り)。
- **出るファイル**: MediaStore に載って app から見えるもの。SD カードを含むか。ゴミ箱・保留中のもの。
- **改名後の MediaStore への通知**: `T04` では行が新しい名前を追ったので不要の見込み。仕様にどう書くか。
- **desktop**: desktop の「画像」「動画」を、OS のファイル選択画面を画像・動画で絞り込む形にするか、枠のままにするか。
- 002 の一覧(行の場所・folder 行・重複の判定)との関係で、002 の意味が動くか(動くなら再承認の対象に入れる)。
