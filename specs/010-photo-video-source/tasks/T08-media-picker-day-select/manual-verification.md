# 手動確認: 日付の見出しでその日をまとめて選ぶ(Androidエミュレータ)

`010:T08` で、「写真・動画」の選択画面の**日付の見出しを押すと、その日の写真・動画(今の絞り込みで並んでいるもの)をまとめて選び、すべて選ばれていればまとめて外す**ようにした(004 REQ-023。代表例 58・59)。見出しの右端の丸い印は、その日がすべて選ばれているかを示す。

**対象buildは、`lib/`・`android/` の内容が task.md の「Evidence revision」に書いた commit と同一のもの**である。
branch `asdd/010-photo-video-source/T08-media-picker-day-select` の HEAD から build すればこれを満たす。
Kotlin は変えていないが、念のため `flutter run` からやり直す。
**code・dependency・build設定が変わったら、この結果は再利用しない。**

## 使う端末と準備

- 起動と`flutter run`は`/workspace/docs/development/emulator-verification.md`のとおり。branchの移動は不要。
- `010:T07`・`T11` の確認で作ったもの(今日撮ったカメラの写真と動画、スクリーンショット、Chrome でダウンロードした Canon_40D.jpg)をそのまま使う。**今日の見出しの下に写真と動画が両方ある**こと。

## 1. 見出しでまとめて選び、もう一度押すと外れる(代表例 58)

1. 「ファイルを選ぶ」→「写真・動画」を開く。何も選ばない。
2. 今日の見出し(日付の文字か、右端の丸)を押す。
3. もう一度押す。

- 2: 今日の写真・動画が**すべて**選ばれ、見出しの右端の丸に印が付く。題名が「N件選択中」(N = 今日の件数)。ほかの日は選ばれない。
- 3: 今日の分がすべて外れ、丸の印も消える。

## 2. 一部だけ選んでいる日はすべて選ぶ(代表例 59)

1. 今日の写真を1枚だけ押して選ぶ(見出しの丸には印が付かない)。
2. 今日の見出しを押す。

- 今日の写真・動画が**すべて**選ばれ、丸に印が付く。

## 3. 絞り込みとの関係

1. ⋮ →「選択をすべて解除」。
2. 今日の**動画を1つ**押して選ぶ。
3. 種類を「写真」にする。
4. 今日の見出しを押す(今日の写真が選ばれる)。
5. もう一度、今日の見出しを押す。
6. 種類を「すべて」に戻す。

- 4: 今日の写真がすべて選ばれる。題名の件数は「今日の写真の数 + 1」(見えていない動画も数える)。
- 5: 今日の写真だけが外れ、題名は「1件選択中」(**見えていない動画は外れない**)。
- 6: 今日の動画だけが選ばれていて、今日の見出しの丸には印が無い。

## 4. ほかの日・ほかの操作

1. いちばん下の「2008年5月30日(金)」の見出しを押す。
2. 長押しの範囲選択、ⓘ、確定がこれまでどおり動くかを軽く確かめる。

- 1: Canon_40D.jpg が選ばれる。
- 見出しの押しやすさ・丸の印の見え方で気になる点があれば教えてほしい。
