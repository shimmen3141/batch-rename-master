# 手動確認: 「写真・動画」の選択画面(Androidエミュレータ)

`010:T06`・`T07` で、Android の種類を「写真・動画」「すべて」の2つにした。「写真・動画」では、端末の写真・動画を撮影日の新しい順に並べた選択画面が開く(004 REQ-011・REQ-022・REQ-023)。

**対象buildは、`lib/`・`android/` の内容が task.md の「Evidence revision」に書いた commit と同一のもの**である。
branch `asdd/010-photo-video-source/T07-android-media-picker-screen` の HEAD から build すればこれを満たす。
**Kotlin(`MainActivity.kt`)は `T06` で変わっていて、この画面で初めて動く。hot reload / hot restart ではなく `flutter run` をやり直す。**
**code・dependency・build設定が変わったら、この結果は再利用しない。**

**この task で見ないもの**(後の task で変わるので、今の見た目で判断しない):

- 日付の見出しを押してその日をまとめて選ぶ操作(`T08`)。今は押しても何も起きない。
- 読み込んだ後の上部の帯の表示と、一覧から開き直す入口(`T09`)。今は帯が folder 名か「複数のフォルダ」になり、開き直す入口は「すべて」の browser のものが出る。

## 使う端末と準備

- 起動と`flutter run`は`/workspace/docs/development/emulator-verification.md`のとおり。branchの移動は不要。
- **`flutter run` が build に失敗したら、そこで止めてエラーをそのまま貼ってほしい**(Kotlin は container で build できない)。
- エミュレータの時刻帯は GMT のままでよい(見出しの日付は端末の時刻帯で出る)。
- PowerShell で、先に次を実行しておく(代表例 65 の確認用。**adb で置いた写真は選択画面に並ばないはず**のもの)。

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
$dir = "$env:TEMP\brm-010-t07"
New-Item -ItemType Directory -Force $dir | Out-Null
Invoke-WebRequest https://raw.githubusercontent.com/ianare/exif-samples/master/jpg/Canon_40D.jpg -OutFile "$dir\adb_canon.jpg"
& $adb shell mkdir -p /storage/emulated/0/Download/brm-010-t07
& $adb push "$dir\adb_canon.jpg" /storage/emulated/0/Download/brm-010-t07/
```

- エミュレータで次を作る(**adb では置かない**。adb で置いたものはアプリから見えない):
  1. カメラで**写真を6枚**、**動画を1本**(5秒ほど)撮る(今日の見出しの下に2行以上並ぶようにするため。1行に4枚ほど並ぶ)。
  2. **スクリーンショットを1枚**撮る(PowerShell なら `& $adb shell input keyevent 120`)。
  3. Chrome で `https://raw.githubusercontent.com/ianare/exif-samples/master/jpg/Canon_40D.jpg` を開き、画像を長押し →「画像をダウンロード」。`Download/` に入る。この写真は EXIF の撮影日時が **2008/5/30**。

## 1. 種類が2つになる(代表例 27)

1. アプリで「ファイルを選ぶ」を押す。

- 種類は「**写真・動画**」「**すべて**」の2つ。「画像」「動画」「文書」は無い。「（未実装）」の表示も無い。

## 2. 全件で開き、撮影日の新しい順に並ぶ(代表例 54・55・65)

1. 「写真・動画」を押す。

- 題名は「写真・動画」。上に「すべてのアルバム ▾」と「すべて|写真|動画」の切り替えがある(「すべて」が選ばれている)。
- **今日の日付の見出し**の下に、カメラの写真6枚・動画・スクリーンショットが**サムネイル**で並ぶ。新しく撮ったものほど左上。
- 動画には右下に**再生時間**(`0:05` など)が出る。写真には出ない。
- 下のほうに「**2008年5月30日(金)**」の見出しがあり、その下に Chrome でダウンロードした写真が**1枚だけ**ある(adb で置いた `adb_canon.jpg` は**並ばない**。同じ絵が2枚あれば adb のものが並んでいる)。
- 右上の ⋮ を開くと「すべて選択」がある。「選択をすべて解除」は**無い**。下の「確定」は**押せない**(代表例 60)。

## 3. 種類とアルバムで絞れる(代表例 55)

1. 「動画」を押す。
2. 「写真」を押す。
3. 「すべて」に戻し、「すべてのアルバム ▾」を押す。
4. 下から出た一覧で「Screenshots」を押す。
5. もう一度アルバムの一覧を開き、「すべてのアルバム」を押す。

- 1: 動画だけが並ぶ。2: 動画が消えて写真だけ。
- 3: アルバムの一覧に **Camera・Screenshots・Download** などが、代表のサムネイルと件数付きで並ぶ。**`brm-010-t07` は無い**(adb で置いたものしか無いため)。動画が `Movies` に入っていれば `Movies` もある。
- 4: スクリーンショットだけが並び、ボタンの文字が「Screenshots」になる。
- 5: 全件に戻る。

## 4. 絞り込みをまたいで選び、確定する(代表例 56・57)

1. カメラの写真を1枚押す(選択の印が付き、題名が「1件選択中」)。
2. アルバムを「Screenshots」に絞り、スクリーンショットを押す(「2件選択中」)。
3. アルバムを「すべてのアルバム」に戻し、種類を「動画」にする(選んだ2枚は見えなくなる)。題名は「2件選択中」のまま。
4. 「確定」を押す。

- 一覧が**その2つ**(カメラの写真とスクリーンショット)に置き換わる。
- **「複数のフォルダのファイルが含まれています」の警告は出ない。**
- 各行の場所が `内部共有ストレージ/DCIM/Camera`・`内部共有ストレージ/Pictures/Screenshots` のような形で出る(保存場所の名前は端末の表示どおりでよい)。

## 5. 長押しの範囲選択・全選択・解除・閉じる(REQ-023)

1. 「別フォルダへ」→「写真・動画」で開き直す(全件・選択なしで始まる)。
2. 今日の見出しの**最初のサムネイルを長押し**し、指を離さずに**次の行のサムネイル**まで動かす。
3. 指を離さずに、最初のサムネイルのすぐ右まで戻してから離す。
4. ⋮ →「選択をすべて解除」。
5. 種類を「写真」にし、⋮ →「すべて選択」。種類を「すべて」に戻す。
6. 左上の × を押す。
7. 何か1つ選んでから、左下の「← リネーム画面へ」を押す。

- 2: 最初のサムネイルから指の下のサムネイルまで、**表示順で間にあるものがすべて**選ばれる(指が通っていないものも)。
- 3: 戻った分の選択が外れる。
- 4: 選択が0になり、「確定」が押せなくなる。
- 5: 写真がすべて選ばれ、動画は選ばれていない。
- 6: すべて外れる。
- 7: 画面が閉じ、一覧は手順4で確定した2つのまま(変わらない)。
- 操作の間、スクロールや drag が引っかかる・サムネイルが出ないなど気になる点があれば教えてほしい。
