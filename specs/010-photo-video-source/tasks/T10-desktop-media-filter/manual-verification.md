# 手動確認: desktop の「写真・動画」の絞り込み(Windows)

`010:T10` で、desktop の「ファイルを選ぶ」の種類を「**写真・動画**」「文書」「すべて」の3つにし、「写真・動画」で**写真と動画のファイルに絞った Windows のファイル選択画面**が開くようにした(004 REQ-011。代表例 13・28)。

あわせて「文書」の絞り込みも直した。`file_selector` の Windows 実装は、拡張子を持たない絞り込みを受け付けない(エラーになる)。今までの「文書」は MIME 型だけを渡していたので、**Windows では選択画面が開かず「ファイルを読み込めませんでした」になっていたはず**である(コードから判断した。Windows では確かめていない)。今は MIME 型と一緒に拡張子を渡す。

**対象buildは、`lib/` の内容が task.md の「Evidence revision」に書いた commit と同一のもの**である。
branch `asdd/010-photo-video-source/T10-desktop-media-filter` の HEAD から build すればこれを満たす。
**code・dependency・build設定が変わったら、この結果は再利用しない。**

## 使う端末と準備

- host(Windows)で同じ worktree から `flutter run -d windows` する。branch の移動は不要。
- 1つのフォルダに、**写真(.jpg か .png)・動画(.mp4 か .mov)・文書(.pdf か .txt)** をそれぞれ1つ以上置く。拡張子が大文字(`.JPG` など)の写真が1つあるとなおよい。

## 1. 種類が3つになっている(代表例 28)

1. 「ファイルを選ぶ」を押す。

- 種類が上から「**写真・動画**」「文書」「すべて」の3つ。
- 「写真・動画」の説明が「**写真・動画のファイルから選ぶ**」。「（未実装）」の文字は無い。

## 2. 「写真・動画」で絞った選択画面が開き、読み込める(代表例 13)

1. 「写真・動画」を選ぶ。
2. 準備したフォルダを開く。
3. 写真と動画を選んで開く。

- 2: 写真と動画だけが並び、文書(.pdf・.txt)は並ばない。大文字の拡張子の写真も並ぶ。
- 3: 選んだ写真と動画が一覧に並ぶ。

## 3. 「文書」と「すべて」

1. 「別フォルダへ」→「文書」で同じフォルダを開き、文書を選んで開く。
2. 「別フォルダへ」→「すべて」で同じフォルダを開く。

- 1: 選択画面が開き、文書だけが並ぶ。選んだ文書が一覧に並ぶ(エラーにならない)。
- 2: 写真・動画・文書のすべてが並ぶ。
