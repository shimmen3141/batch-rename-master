# 手動確認: 選択画面の日付を作成日時に揃える・ⓘ の説明(Androidエミュレータ)

`010:T11` で、「写真・動画」の選択画面の並び順と見出しの日付を、MediaStore の撮影日時(`DATE_TAKEN`)が無い写真・動画について、**読み込んだ後の作成日時と同じ**にした(004 REQ-022)。題名の右の ⓘ で、並び順と日付の決め方の説明が開く。

**対象buildは、`lib/`・`android/` の内容が task.md の「Evidence revision」に書いた commit と同一のもの**である。
branch `asdd/010-photo-video-source/T11-align-picker-dates` の HEAD から build すればこれを満たす。
**Kotlin(`MainActivity.kt`)を変えたので、hot reload / hot restart ではなく `flutter run` をやり直す。**
**code・dependency・build設定が変わったら、この結果は再利用しない。**

## 使う端末と準備

- 起動と`flutter run`は`/workspace/docs/development/emulator-verification.md`のとおり。branchの移動は不要。
- **`flutter run` が build に失敗したら、そこで止めてエラーをそのまま貼ってほしい。**
- `010:T07` の確認で作ったものをそのまま使う。無ければ作る(**adb では置かない**):
  1. Chrome で `https://raw.githubusercontent.com/ianare/exif-samples/master/jpg/Canon_40D.jpg` を開き、画像を長押し →「画像をダウンロード」(EXIF の撮影日時 2008/5/30 15:56。MediaStore の `datetaken` は空)。
  2. カメラで写真を1枚以上撮る。スクリーンショットを1枚撮る(PowerShell なら `& $adb shell input keyevent 120`)。

## 1. ダウンロードした古い写真が撮影日の見出しに並ぶ(代表例 67)

1. アプリで「ファイルを選ぶ」→「写真・動画」を押す。
2. いちばん下までスクロールする。
3. 「2008年5月30日(金)」の見出しの下の写真を押して選び、「確定」を押す。

- 2: **「2008年5月30日(金)」の見出し**があり、その下に Chrome でダウンロードした写真が1枚ある。今日の見出しには、この写真は**無い**(`T07` のときとの違い)。
- 3: 一覧の `作成日時:` が **2008/5/30 15:56**(選択画面の見出しと同じ日)。

## 2. カメラの写真・スクリーンショットは今までどおり(代表例 68)

1. 「別フォルダへ」→「写真・動画」で開く。

- カメラの写真とスクリーンショットは、撮った日(今日)の見出しの下に並ぶ。

## 3. ⓘ で説明が開き、閉じても選択と絞り込みは変わらない(代表例 69)

1. 題名「写真・動画」の**すぐ右の ⓘ** を確かめる。
2. 写真を1枚押して選ぶ(題名が「1件選択中」になる)。ⓘ が同じ位置に残っていることを確かめる。
3. 種類を「写真」にする。
4. ⓘ を押す。
5. 「閉じる」を押す。

- 4: ダイアログが開き、次が読める:
  - 題「並び順と日付について」
  - 「写真・動画は撮影日時の新しい順に、日付ごとにまとめて並びます。」
  - 角丸の枠(左に色の帯とファイルのアイコン)に「端末が撮影日時を把握できないものは、ファイル内部に記録された作成日時で並びます。」と、その下に小さく「・ダウンロードしたファイルなど」
  - もう1つの枠(色の帯と端末のアイコン)に「撮影日時・ファイル内部の作成日時のどちらも無いものは、この端末に保存された日時で並びます。」と「・多くのスクリーンショットなど」
- 見た目(枠・色・アイコン)が不自然・読みにくいところがあれば教えてほしい。
- 5: ダイアログが閉じ、題名は「1件選択中」のまま、種類は「写真」のまま。

## 4. 今までの操作が壊れていない

1. 種類(すべて|写真|動画)とアルバムで絞る。
2. 絞り込みをまたいで2つ選び、確定する。
3. 長押しして指を動かす範囲選択、⋮ の「すべて選択」「選択をすべて解除」。

- `010:T07` の確認と同じに動く(絞っても選択は残る、確定で2つに置き換わり警告は出ない、範囲選択が効く)。

## 5. 開く速さ

1. アプリを起動し直し、「写真・動画」を開く。開くまでの時間を見る。
2. 「← リネーム画面へ」で閉じて、もう一度開く。

- 1: 読み込み中の表示の後、すぐ(数秒以内)並ぶ。端末の写真・動画の数も教えてほしい(アルバムの一覧の件数の合計でよい)。
- 2: 1回目と同じか、より速い(中身の日時は覚えている)。
