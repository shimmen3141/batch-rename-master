# 手動確認: 上部の「リネーム画面へ戻る」の帯(Androidエミュレータ)

`015:T01` で、**browser(「すべて」)と写真・動画の選択画面のいちばん上に、色の違う帯**を足し、左に「**リネーム画面へ戻る**」(矢印なし)を置いた。押すと footer 左下の「← リネーム画面へ」と同じく、選んだものを捨ててリネーム画面へ戻る。header(`←` 上のフォルダへ・選択中の `×`・題名・ⓘ・ケバブ)と footer は変えていない。

この確認の目的は、**今の配置と見比べて、採るかどうかを決めること**である。採らなければ merge しない。

**対象buildは、`lib/`・`android/` の内容が task.md の「Evidence revision」に書いた commit と同一のもの**である。
branch `asdd/015-screen-switch-placement/T01-top-return-band` の HEAD から build すればこれを満たす。Kotlin は変えていない。
**code・dependency・build設定が変わったら、この結果は再利用しない。**

## 使う端末と準備

- 起動と`flutter run`は`/workspace/docs/development/emulator-verification.md`のとおり。**普段の作業ツリーは branch の移動が不要**(すでに T01 の branch にある)。
- **見比べ用の今の配置**は、Agent が別の worktree に用意した: リポジトリの `.worktrees/015-T01-compare-dev`(`dev` の `7f14151`。T01 を含まない)。ここは見比べのためだけのもので、普段の作業ツリーは動かさないための例外である。
- これまでの確認で作った写真・動画をそのまま使う。

## 1. 今の配置を撮る(`dev`)

1. host のターミナルで `.worktrees/015-T01-compare-dev` へ移り、`flutter pub get` のあと `flutter run` する。
2. 「ファイルを選ぶ」(または「別フォルダへ」)→「すべて」で、ファイルのあるフォルダ(例: `DCIM/Camera`)を開く。**何も選んでいない画面**と、**1つ選んだ画面**のスクリーンショットを撮る(エミュレータの横のカメラのボタン)。
3. 「← リネーム画面へ」で戻り、「写真・動画」を開いて、同じく**選択0件**と**1件選んだ画面**を撮る。
4. `q` で終える。

## 2. 新しい配置を見る(T01)

1. 普段の作業ツリー(`/workspace` と同じ場所)で `flutter run` からやり直す。
2. 手順1の2・3と同じ画面を開いて撮る。

- browser でも選択画面でも、**いちばん上に色の違う帯**があり、左に「リネーム画面へ戻る」(矢印なし)がある。
- その下の header は今と同じ(browser は `←` と保存場所名・ケバブ、選択中は `×` と「N件選択中」。選択画面は題名・ⓘ・ケバブ)。
- footer の「← リネーム画面へ」と「確定」も今と同じ。

## 3. 帯から戻る

1. browser で1つ選んだ状態のまま、帯の「リネーム画面へ戻る」を押す。
2. 写真・動画の選択画面でも、1つ選んだ状態のまま押す。

- どちらもリネーム画面へ戻り、**一覧は開く前のまま**(選んだものは入らない)。

## 4. 見比べて決める

手順1と手順2のスクリーンショットを見比べ、次を教えてほしい。

- **採るか・採らないか**(採らなければ merge しない)。
- 気になる点(帯の色・高さ・文字の大きさ・押しやすさ、縦の余白が減ったこと)。
- footer の「← リネーム画面へ」を**残すか外すか**の希望(`T02` で扱う。今は決めなくてもよい)。
