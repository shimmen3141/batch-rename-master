# T28 manual確認: まとめて外す選択モード

共通の起動手順は [`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md) を読む。
**branchの移動は不要**である(Agentが対象commitのまま待機している)。

対象: `008 / T28 まとめて外す選択モードを実装する`(002 REQ-016 / REQ-017 / REQ-018)

## 準備

demoの初期値(9件。うちカメラ5件、ダウンロード4件)をそのまま使う。
**実ファイルは触らない** — demoのハンドルは `demo:` で始まる作り物である。

1. app を起動する。
2. 下部の「変更する名前を設定する」から**連番トークンを含むルール**を作る
   (例: 連番のみ)。**これでドラッグ用のつまみが出る**(002 REQ-014。つまみが出るのは
   連番があるときだけで、押し間違いが起きうるのはこの状態である)。

## 手順1: 通常表示に × が無い(REQ-016・代表例 6e)

1. 一覧の行を見る。

- **確認A**: 行の右端に**つまみだけ**があり、**× が無い**。
- **確認B**: ヘッダに「〇 件」と**「外すファイルを選ぶ」**がある。
- **確認C**: 行を**普通にタップ**しても何も起きない(選択も除去も始まらない)。

## 手順2: 長押しでモードへ入る(REQ-018・代表例 6f)

1. 行のどれかを**長押し**する。

- **確認A**: ヘッダが **×(やめる) / 「外すファイルを選ぶ」 / 「1 件」 /
  「リネーム候補から外す」** に入れ替わる。
- **確認B**: **長押しした行が選ばれている**(チェックが付いている)。
- **確認C**: **つまみが消えている**。並び順chipの**「カスタム順」も消えている**。
  「元の名前順」などのソートは**残っている**。
- **確認D**: 一覧の中身は変わっていない(件数も並びもそのまま)。
- **確認E**: いったんモードをやめ、**つまみを長押ししてから(1秒ほど押したまま)上下へドラッグ**する。
  **並び替えができる**こと。選択モードが開いてしまわないこと
  (独立reviewが実機と同じgesture解決で、0.5秒以上保持すると並び替えがモードに奪われる
  不具合を見つけた箇所である)。

## 手順3: まとめて外して1回で戻す(REQ-018・代表例 6g/6h)

1. もう1行タップして**2件**選ぶ(件数が「2 件」になる)。
2. 「リネーム候補から外す」を押す。

- **確認A**: 選んだ2件が一覧から消え、**モードが抜けている**(ヘッダが「〇 件」に戻る)。
- **確認B**: 「2 件を一覧から外しました」という通知が出て、**「元に戻す」**がある。
- **確認C**: 「元に戻す」を押すと、**2件とも元の位置へ**戻る(末尾に付かない)。

## 手順4: やめても一覧は変わらない(代表例 6i)

1. 長押しでモードへ入り、2〜3件選ぶ。
2. ヘッダの **×** を押す。

- **確認A**: 一覧は**何も変わっていない**(選んだ行も残っている)。
- **確認B**: もう一度モードへ入ると、**件数が「0 件」**である(前回の選択が残らない)。
- **確認C**: **端末の戻る**でも同じようにモードだけが終わる(画面は閉じない)。

## 手順5: 0件では外せない(REQ-018)

1. ヘッダの「外すファイルを選ぶ」から入る(長押しではなく、こちらから)。

- **確認A**: 件数が「0 件」で、**「リネーム候補から外す」が押せない**(灰色)。
- **確認B**: 1件選ぶと押せるようになる。

## 手順6: 狭い画面と大きい文字

1. 端末の文字サイズを**最大**にする(設定 → ディスプレイ → 文字サイズ)。
2. モードへ入る。

- **確認A**: ヘッダの**件数と「リネーム候補から外す」がどちらも読める**
  (行が折り返してもよい。消えたり切れたりしていないこと)。
- **確認B**: 一覧が潰れていない(行が見えている)。

## 結果の受け取り

各確認の成否を自由形式で返してよい。**気づいたこと・違和感も一緒に**書いてよい
(受け取った後、Agentが `task.md` へ証拠として記録する)。
