- 今の並び順は横並びの chip(`_SortBar`)。`カスタム順` の chip は連番があるときだけ出る(REQ-014。`manualOrderMatters`)。`setSortMode(custom)` は並べ替えず `custom` と表示するだけ。

### 開発者の決定(2026-09-30)

「ファイルを読み込んだとき(最初と読み込み直し)の並び順」を尋ねた(3択)。回答: **「名前順で始め、以後は維持」**(推奨案) — 最初の読み込みは名前の昇順。読み込み直しではそのとき選んでいる並び順(keyと昇降)を当てはめる。直前が「カスタム」なら名前の昇順へ戻す。plan の「人間の決定」へ記録した。
