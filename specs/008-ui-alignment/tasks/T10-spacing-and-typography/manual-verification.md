## 0. いま動いているのが、このbuildか確かめる

起動直後、画面の一番上に**「一括リネーム」の帯が無く**、フォルダ名の帯から始まっていれば、このbuildである。

## 1. 上部(フォルダ名の帯)

**こうなってほしい**

- フォルダ名の帯が、端末の時計・電池の表示(status bar)の**下から**始まる。時計の表示と重なっていない。
- フォルダ名が**白**で、以前より**少しだけ大きい**。
- 「別フォルダへ」のボタンに**アイコンが無く**、文字だけになっている。
- フォルダ名の左の小さなフォルダのアイコンは残っている。

## 2. 一覧の行

1. 下部の「命名ルールを設定する」を押し、「＋ 自由テキスト」で値 `a` を1つだけ足して一覧へ戻る。各行に変更後の名前が出る(`IMG_` の3行などには「重複」の警告も出る)。

**こうなってほしい**

- 行の左の**写真が以前より大きい**(40 → 52)。
- **変更前の名前**(上の行)が、変更後の名前より**小さく、色が薄い**。それでも読める。
- **変更後の名前**(矢印の右)が**太字**で、変更前より大きい。
- 行と行の間の線が、以前より**少しだけ**はっきり見える。目立ちすぎて一覧がうるさく見えることはない。

## 3. 文字サイズ最大での行の警告(`008:T18` の確認Cの続き)

手順2の状態のまま、端末の設定で**文字サイズ(フォントサイズ)を最大**にして、アプリへ戻る。

**こうなってほしい**

- 警告の「！」のマークが、警告文と同じくらいの大きさで、**文字に対して上や下へずれていない**(以前は文字を大きくするほど「！」が小さく、上へ浮いていた)。
- 警告文が「…」で切れていない。

## 4. 文字サイズ最大での全体

文字サイズを最大のまま、上部の帯・一覧・下部のボタンを眺める。

**こうなってほしい**

- 画面からはみ出す所や、文字が欠ける所が無い。フォルダ名の帯で「別フォルダへ」が押し出されていない。
- 一覧は狭くなるが、行が少なくとも1行は見えてスクロールできる(低い画面で一覧が狭くなるのは、2026-10-01 に受容した)。

確認後、文字サイズを元へ戻す。

## 5. Windows desktop

hostで同じworktreeから`flutter run -d windows`する。起動直後のデモの一覧を使う(ファイルは選ばなくてよい)。

1. 窓を広げた状態で見る(一覧とルール設定が左右に並ぶ)。
2. 窓の幅を狭め、一覧だけの形(下部にボタンが出る形)にして見る。
3. Windows の「設定 → アクセシビリティ → テキストのサイズ」を**最大(225%)**にしてアプリへ戻り、1・2 をもう一度見る。確認後、元へ戻す。

**こうなってほしい**

- 「一括リネーム」の帯が無く、フォルダ名の帯から始まる。
- **歯車**がフォルダ名の帯の**右端、「別フォルダへ」の右**にあり、帯の中に収まって押せる(押すと「更新日時を一覧の並び順にずらす」のメニューが開く)。
- 手順1・2の見え方(フォルダ名が白で少し大きい、ボタンにアイコンが無い、写真が大きい、変更前は小さく薄く・変更後は太字)が同じである(行に変更後の名前を出すには、広い窓では右側のルール設定で、狭い窓では下部の「命名ルールを設定する」から、「＋ 自由テキスト」で `a` を1つだけ足す)。
- 文字を最大にしても、はみ出す所や文字が欠ける所が無い。警告の「！」が文字に対してずれていない。
