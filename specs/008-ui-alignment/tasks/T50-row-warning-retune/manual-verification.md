# 手動確認: 行の警告の出し方と、連番の桁の自動引き上げ(Androidエミュレータ・Windows desktop)

`008:T50`(行の警告の再調整)と `008:T52`(件数が増えたときの連番の桁の自動引き上げ)を**同じ build で**確かめる。

**対象buildは、`lib/`・`hook/`・`src/`の内容が commit `bcc2c34` と同一のもの**である(1回目)。branch `asdd/008-ui-alignment/T50-row-warning-retune` のHEADからbuildすればこれを満たす。**code・dependency・build設定が変わったら、この結果は再利用しない。**

文言・位置・色・下線と、件数が増えたときの引き上げは自動testで確かめてある。ここで見るのは**実機の字体での見え方と、押しやすさ**である。

## 使う端末と準備

- 起動と`flutter run`は`/workspace/docs/development/emulator-verification.md`のとおり。**host側でworktree `.worktrees/008-T50-row-warning-retune` へ`cd`してから`flutter pub get` → `flutter run`**する(branchの移動は不要)。
- ファイルは選ばなくてよい。起動直後のデモの一覧(`IMG_0009.jpg` など9件)を使う。リネームは実行しない。
- 前に別の build で命名ルールを作っていた場合は、そのルールが復元されて出る。下の各手順は、ルールのチップを全部消した状態から始める。

## 0. いま動いているのが、このbuildか確かめる

下部の「命名ルールを設定する」を押し、「＋ 自由テキスト」で値 `a` を1つだけ足して一覧へ戻る。`IMG_` の行などで、**変更前の名前と同じ行の右端**に赤い「！重複」(下線つき)が出ていれば、このbuildである(以前は名前の上に、赤い枠の箱が1行で出ていた)。

## 1. 重複

手順0の状態のまま見る。

**こうなってほしい**

- 「！重複」が、変更前の名前と**同じ行の右端**(つまみの左)にある。名前の上に専用の行は無い。
- 「重複」が**太字・下線**で、押せると分かる。押すと、その行の詳細が開く。指で押しにくくない。
- 変更前の名前が長い行では、名前のほうが「…」で切れ、「！重複」は欠けない。
- 警告のある行が、無い行より大きく高くなっていない。

## 2. 作成日時不明

ルールのチップを全部消し、「＋ 元の名前」→「＋ 日時」(基準は作成日時のまま)を足して一覧へ戻る。

**こうなってほしい**

- `Screenshot_20260304.png` の行だけ、小さい灰色の文字の「作成日時: 不明」が**赤**になっている(並び順は名前順のままでも赤)。
- その行の右端は「！詳細」。押すと、その行の詳細が開き、作成日時が取れないことが読める。
- ほかの行(作成日時が取れている行)は赤くならず、右端にも何も出ない。

## 3. 名前が空

ルールのチップを全部消し、「＋ 日時」(作成日時)だけにして一覧へ戻る。

**こうなってほしい**

- `Screenshot_20260304.png` の行の右端が「！名前が空」で、変更後の名前の欄が「（変更なし）」。「作成日時: 不明」は赤。
- 「！名前が空」を押すと、名前が空になるので改名されないことが詳細で読める。

## 4. 連番の桁の自動引き上げ(`008:T52`)

デモの一覧は9件で増やせないので、**1件外した状態でルールを作り、アプリを起動し直して9件へ戻す**。

1. ルールのチップを全部消す。
2. 一覧の右上の「︙」→「外すファイルを選ぶ」で、行を1つだけ選んで「1件を外す」を押す(8件になる)。
3. 「命名ルールを設定する」(広い窓では右のルール設定)で「＋ 連番」を押し、**開始番号を2、桁数を1**にして追加する(8件・開始2なので最大9、1桁で足りる)。
4. アプリを完全に終了してから起動し直す(`flutter run` の画面で `R` を押す再起動でもよい)。デモの一覧は9件に戻り、ルールは前回のものが復元される。

**こうなってほしい**

- 起動直後に、「ファイルの数に合わせて、連番の桁数を1桁から2桁へ増やしました」という通知が出る。
- ルールのチップが「連番(2桁)」になり、変更後の名前が `02`〜`10` の2桁になる。行に「桁不足」は出ない。
- 通知は自分で閉じられる(右上の ×)。閉じても桁は2のまま。

確認後、ルールのチップを全部消しておく(次に起動したとき引き上げの通知が出ないように)。

## 5. 文字サイズ最大

手順0(「＋ 自由テキスト」で `a`)のルールにし、端末の設定で**文字サイズを最大**にしてアプリへ戻る。

**こうなってほしい**

- 「！重複」の「！」が文字に対して上下にずれていない。「重複」が欠けない(名前のほうが切れる)。
- 画面からはみ出す所が無い。

確認後、文字サイズを元へ戻す。

## 6. Windows desktop

hostで同じworktreeから`flutter run -d windows`する。

1. 広い窓(右にルール設定)と狭い窓(下部にボタン)のそれぞれで、手順1〜3を見る。
2. 手順4を広い窓で行う(右のルール設定で連番を足す。起動し直しはアプリを閉じて `flutter run -d windows` をもう一度)。

**こうなってほしい**

- 手順1〜4と同じに見える。マウスで「！重複」などに乗せると押せる形になり、押すと詳細が開く。
