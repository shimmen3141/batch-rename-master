# 手動確認: ルール構築シートを参考デザインへ(Androidエミュレータ)

**対象buildは、`lib/`・`hook/`・`src/`の内容が task.md の「Evidence revision」に書いた code commit と同一のもの**である。branch `asdd/008-ui-alignment/T45-rule-sheet-presentation` のHEADからbuildすればこれを満たす。**code・dependency・build設定が変わったら、この結果は再利用しない。**

**Androidエミュレータで確認する**(`008:T39`で開発者が決めた方針)。見た目と操作を見るので debug build でよい。見比べる参考デザインは`docs/design/Bulk Renamer.html`(ブラウザで開き、下部のルールを押すとシートが出る)。

## 使う端末と準備

- host側でworktree `.worktrees/008-T45-rule-sheet-presentation` へ`cd`してから`flutter pub get` → `flutter run`する(branchの移動は不要)。共通の手順は[`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md)。
- ファイルは`008:T25`のfixture(`Download/asdd-008-t25`の3件。改名後の名前でもよい)を使う。**無ければ**、[`008:T25`の手順書](../T25-dismissible-toast/manual-verification.md)の「準備するファイル」を実行する。
- 「ファイルを選ぶ」→「すべて」→ `Download` → `asdd-008-t25` で3件を選んで確定する。
- 縦向き(狭幅)で始める。

## 1. シートの枠

1. 下の「**命名ルール**」のボタンを押す。
   - 下からシートが出る。上端が**角丸**で、中央に**取っ手**(短い横棒)。
   - 上に見出し「**命名ルール**」と、その下に区切り線。
   - 「**閉じる**」ボタンは**無い**。
2. ルールが空なら、今あるトークンを×で消して空にする。
   - 見出しの下の線と点線の枠の間に**空きがある**(案内の文は出ていない)。
   - 暗い面に**点線の枠**があり、中に「↓ 下のボタンから要素を追加」。
   - 枠の下に追加ボタンが並ぶ(塗りの無い、**枠線だけ**のボタン)。

## 2. チップ(種類ごとの色と、1件目での値)

1. 「＋ 元の名前」→「＋ 区切り」(`_` のまま「追加」)→「＋ 連番」(そのまま「追加」)→「＋ 日時」(そのまま「追加」)の順に足す。
   - 枠の中に4つのチップが横に並ぶ。チップは**種類ごとの色**で、上段の**左**に小さな種類名、**右上の角**に削除の**円**(中に×)、下段に大きな値:
     - **灰**「元名」`[元のファイル名]`
     - **黄**「区切り」`_`
     - **緑**「連番」`01`
     - **紫**「作成日時」一覧の1件目の作成日時(例 `20260929`。取れないファイルなら「不明」)
   - 削除の円は、**円の上端と右端がチップの上辺と右辺に重なる**位置にある。円の縁と×は**チップの色**、円の中は**チップの面と同じ色**。
   - 見出しの下の線と点線の枠の間に「**チップを押すと各設定が開けます。チップを長押ししてドラッグすると並び替えられます。**」(点線の枠の中には書かれていない)。
2. チップ(例: 連番)を**タップ**する。
   - 設定のダイアログ(`T44`)がシートの上に開く。「キャンセル」で閉じる。
3. 削除の円の**×から少し外れた所**(円の中)を押す。
   - そのチップが消える(円の大きさの分だけ押しやすくなっている)。消したチップは「＋」から足し直しておく。

## 3. 並べ替え(点線の枠の中)

1. 「連番」のチップを**長押し**し、そのまま**左へ**動かして「元名」より前で離す。
   - 連番が先頭に移る。下のプレビューの新しい名前も `01_…` の形に変わる。
2. チップを**押してすぐ**横に動かす。
   - 並べ替わらない(チップが多くて枠からはみ出しているときは、枠が横にスクロールする)。
3. チップを増やして枠からはみ出させ(「＋ 自由テキスト」で何か足すなど)、枠を横にスワイプする。
   - 枠の中だけが横にスクロールする。

## 4. プレビュー

1. シートの下部を見る。
   - 区切り線の下に「**プレビュー（1つ目のファイル）**」、その下に1件目の**元の名前**(赤みがかった色で**取り消し線**)、その下に「→」(**濃い色**で見やすい)と**新しい名前**(緑)。
   - プレビューの下に**少し余白**があり、画面の下端ぎりぎりではない。
2. トークンを×で消して「元名」だけにする。
   - 元の名前が灰色(取り消し線なし)になり、「**（変更なし）**」と出る。
3. トークンを足しても、チップは枠の中で横に並ぶだけで、**シートの高さは変わらない**。
   - (任意)画面の高さが足りない向き・端末(横向きにしても2ペインにならない端末など)では、シートは画面のおよそ8割より高くならず、シートの中を上下に**スクロール**してプレビューまで見られる。
4. シートの外(上の暗い所)を押すか、下へスワイプして閉じる。

## 5. 広幅(任意)

エミュレータを横向きにして2ペインにし(幅が足りない端末なら省く)、右のルールを見る。

- チップが縦向きのシートと同じ見た目(種類ごとの色、種類名と値、点線の枠)。見出しとプレビューは無い(左に一覧が見えているため)。
