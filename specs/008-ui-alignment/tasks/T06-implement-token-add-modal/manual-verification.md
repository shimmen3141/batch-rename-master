# 手動確認: token追加の確定手順

## 何を確かめてほしいか

`008 / T06`(token追加をmodal確定へ変える)で、ルールの「＋ 自由テキスト」「＋ 区切り」「＋ 連番」「＋ 日時」を
押したときに**すぐ入れず、エディタで「追加」を押したときだけ入る**ようにしました。

自動testが既に押さえているもの(開いただけでは入らない・キャンセル/戻る/シート外tap/下スワイプで閉じると
入らない・「元の名前」は即追加・空のまま追加できない・狭幅でエディタを閉じてもルール設定シートは残る)は
**手順に入れていません**。ここでお願いするのは、**実機で触らないと分からないこと**だけです。

|---|---|

## 事前準備

ファイルは何でも構いません。[`008 / T07` のfixture](../T07-row-and-warning-presentation/manual-verification.md)(`DCIM/t07-fixtures`。`adb push` で置く)を使えます。数件を読み込み、全選択にします。
下部の「命名ルール」を押してルール設定シートを開き、トークンを**すべて削除**して空にします。

## 手順1 — 追加が「設定してから入る」と分かる(2分)

1. 「＋ 連番」を押します。

- **確認A**: 連番の設定が開き、下の button が **「追加」** になっている。「押したらもう入ってしまった」と感じない。
- **確認B**: 桁数を変えて「追加」を押すと、設定が閉じて**ルール設定シートに戻り**、その桁数で連番が1つ入っている。

> 設定はルール設定シートより背が高く、開いている間は後ろのトークンの列が見えません。
> 「開いただけでは入らない」ことは自動testで確かめてあるので、ここでは見る必要はありません。

2. 「＋ 自由テキスト」を押します。

- **確認D**: **キーボードが開いても入力欄と「追加」が隠れない。**
- **確認E**: 何か入力して「追加」を押すと入る。

## 手順2 — やめ方が自然に効く(2分)

1. 「＋ 日時」を押し、基準を「更新日時」にしてから、**端末の戻る操作**(ジェスチャーまたは戻るbutton)をします。

- **確認A**: 日時の設定だけが閉じ、**ルール設定シートは開いたまま**。トークンは増えていない。

2. もう一度「＋ 日時」を押し、**設定の上の暗い部分を押します。**

- **確認B**: 同じく設定だけが閉じ、トークンは増えていない。**ルール設定シートまで一度に閉じてしまう、ということがない**。

3. 「＋ 区切り」を押し、**設定を下へスワイプ**します。

- **確認C**: 設定が閉じ、トークンは増えていない。スワイプしようとして**意図せず別のものを押してしまう**ことがない。

## 手順3 — 既存トークンの編集(1分)

1. 手順1で入れた連番を押します。

- **確認A**: 設定が開き、button が **「確定」** になっている(追加と見分けられる)。
- **確認B**: 桁数を変えてから戻る操作で閉じると、トークンは元の桁数のまま。
