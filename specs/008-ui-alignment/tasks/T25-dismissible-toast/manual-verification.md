# 手動確認: 通知(toast)の見た目と閉じる操作(Androidエミュレータ)

**対象buildは、`lib/`・`hook/`・`src/`の内容が commit `1005f11` と同一のもの**である(2回目。1回目は`a207dae`で、結果は`task.md`)。branch `asdd/008-ui-alignment/T25-dismissible-toast` のHEADからbuildすればこれを満たす。**code・dependency・build設定が変わったら、この結果は再利用しない。**

**Androidエミュレータで確認する**(`008:T39`で開発者が決めた方針)。見るのは**見た目と閉じる操作**で、速さは見ないので debug build でよい。

## 使う端末と準備

- 起動と`flutter run`は[`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md)のとおり。**host側でworktree `.worktrees/008-T25-dismissible-toast` へ`cd`してから`flutter pub get` → `flutter run`**する(branchの移動は不要。エミュレータが1台なら`-d`は要らない)。
- `adb devices`にエミュレータが**1台だけ**出ていることを確かめる。

### 準備するファイル

確認専用のフォルダ`Download/asdd-008-t25`だけを使い、**既にあれば何も置かずに止まる**。

```powershell
$adbPath = Join-Path $env:LOCALAPPDATA 'Android\Sdk\platform-tools\adb.exe'
$d = '/sdcard/Download/asdd-008-t25'
$existing = "$(& $adbPath shell "if [ -e $d ]; then echo exists; fi")".Trim()
if ($existing -eq 'exists') {
  Write-Host '端末に Download/asdd-008-t25 が既にあります。何も置かずに止めました。' -ForegroundColor Red
} else {
  & $adbPath shell "mkdir -p $d"
  & $adbPath shell "echo a > $d/a.txt"
  & $adbPath shell "echo b > $d/b.txt"
  & $adbPath shell "echo c > $d/c.txt"
  & $adbPath shell "ls $d"
}
```

**期待**: `a.txt` `b.txt` `c.txt` の3つが出る。

**上のcommandが「既にあります。何も置かずに止めました」と出した場合は、ここで止まる。** そのフォルダはこの手順が作ったものではないかもしれないので、**中身を確かめ、何のフォルダか分かるまで先へ進まず、後片付けでも消さない**(知らせてほしい)。

**後片付け**: **このcommandが作った場合だけ**、確認が終わったら端末のファイルアプリで`Download/asdd-008-t25`を消してよい(中身はすべてこの手順で置いたもの。改名後の名前になっていてもよい)。

## 0. いま動いているのが、このtaskのbuildか確かめる

## 1. 案内の通知(i・青)

1. 「ファイルを選ぶ」→「**画像**」を選ぶ。

**こうなってほしい**

- **フッターの少し上**に、**背景より一段明るいカード**で「『画像』の読み込みは写真機能で対応予定です」が出る。**リネームのbuttonやルール設定に重ならない。**
- **先頭に青いiのアイコン**、**カードの左端に細い青い帯**。**カード全体は青く塗られていない。**
- **右上に円の×**があり、**円がカードの右上の角に一部重なって**いる(少しはみ出している)。
- ×を押すと、**すぐに消える**。押さなくても数秒で自動で消える。

## 2. 除去の通知(✓・緑、「元に戻す」あり)

1. 「ファイルを選ぶ」→「すべて」→ `Download` → `asdd-008-t25` で3件を選んで確定する。
2. リネーム画面で1件を一覧から外す: 右上の**︙ →「外すファイルを選ぶ」**(または行を長押し)→ 1件を選ぶ → 上の段の**外すアイコン**(赤い、リストに−の形)を押す。

**こうなってほしい**

- 「1 件を一覧から外しました」がカードで出る。**先頭に緑の✓**、**左端に緑の帯**。(外す操作の間はフッターが隠れるので、このときは画面の下端近くに出る。)
- 本文の右に「**元に戻す**」(シアンを薄く敷いた角丸のbutton)がある。**右上の×とは離れていて、取り違えにくい。**
- **30秒ほど待っても消えない**(以前と同じく、この通知は自動では消えない)。
- **右上の×を押すと通知だけが消え、外したファイルは戻らない**(一覧は2件のまま)。

3. もう一度1件外し、今度は「**元に戻す**」を押す。

- 通知が消え、外したファイルが**元の位置**へ戻る。

## 3. 改名の結果(✓・緑、「元に戻す」あり)

1. 3件が一覧にある状態で、命名ルールを適当に変え(例: 先頭に文字列`x_`)、リネームを実行する。

**こうなってほしい**

- 「3 件を改名しました」が**フッターの少し上**にカードで出る。緑の✓と緑の帯、「元に戻す」、右上の×。**リネームのbuttonに重ならず、通知が出ている間もリネームのbuttonやルール設定を押せる。**
- **5秒ほどで自動で消える**(元に戻せる時間が過ぎたら消える。以前と同じ)。
- もう一度実行して、今度は**すぐに右上の×**を押す → 通知だけが消え、**改名は戻らない**。

## 4. エラーの通知(!・赤)

1. 一覧にファイルがある状態で、エミュレータの**設定 → アプリ → `batch_rename_master`(このアプリ)→ 権限 → すべてのファイルへのアクセス**を**許可しない**にする。
2. アプリへ戻り、リネームを実行する。

**こうなってほしい**

- 「『すべてのファイルへのアクセス』が許可されていないため、名前を変更できませんでした。…」が暗いカードで出る。**先頭に赤い!(丸の中に!)**、**左端に赤い帯**。**カード全体は赤く塗られていない。**
- 右上の×で消せる。

3. 確認が終わったら、**権限を許可に戻す**(次の確認のため)。

**権限を外したときにアプリが再起動され、一覧が空になった場合は、この節は飛ばしてよい**(Androidは権限を取り消すとappのprocessを止めることがある)。エラーの見せ方はwidget testとmutation `M440`・`M441`で固定してある。飛ばしたときは、そう報告に書いてほしい。

## 5. 大きい文字

1. エミュレータの設定で**フォントサイズを最大**にする(終わったら戻す)。
2. 1(「画像」)と2(除去)をもう一度出す。

- 文字が折り返してもカードからはみ出さず、**×と「元に戻す」が重ならない**。どちらも押せる。
