# 手動確認: 一覧の folder 行から同じ folder を開き直す(Androidエミュレータ)

`008:T56` で、一覧の先頭に folder 行を置き、右端の `＋ 追加` から**同じ folder を、一覧にあるファイルを選択済みにして**
開き直せるようにした(004 REQ-021 / 002 REQ-021)。

**対象buildは、`lib/`・`hook/`・`src/`の内容が、task.md の「Evidence revision」に書いた commit と同一のもの**である。
branch `asdd/008-ui-alignment/T56-implement-same-folder-reselect` のHEADからbuildすればこれを満たす。
**code・dependency・build設定が変わったら、この結果は再利用しない。**

## 使う端末と準備

- 起動と`flutter run`は`/workspace/docs/development/emulator-verification.md`のとおり。branchの移動は不要
  (`/workspace` はすでにこのbranchにある)。host側で`flutter pub get` → `flutter run`する。
- **ファイルが5件以上ある folder** を1つ用意する(前回までの確認の folder でよい)。以下では a〜e と書く。
- 改名するので、消えても困らないファイルを使う。

## 0. 起動直後(デモデータ)

- デモデータは2つの folder に分かれているので、**folder 行は出ない**。

## 1. folder 行が出る

1. 「ファイルを選ぶ」→「すべて」で用意した folder を開き、**a と b だけ**を選んで確定する。

**こうなってほしい**

- 一覧の先頭(並び順の行と一覧の間)に、細い **folder 行**(folder のアイコン・folder 名・右端の `＋ 追加`)が出る。
- **上部の帯にも同じ folder 名が出ている。重複が気になるかどうかを教えてほしい**(気になるなら別に扱う)。

## 2. 開き直して足す・外す

1. folder 行の**名前のあたり(`＋ 追加` 以外)**を押す → 何も起きない。
2. `＋ 追加` を押す → browser が**その folder で開き**、**a と b にチェックが付いて**「2件選択中」と出る。
3. c を足して確定する → 一覧が a, b, c になる。
4. もう一度 `＋ 追加` → a, b, c にチェックが付いている。b を外して確定する → 一覧が a, c になる。
5. もう一度 `＋ 追加` → 何も変えずに「← リネーム画面へ」で閉じる → 一覧は a, c のまま。

## 3. 手で並べた順が残る

1. 一覧で c を a の上へドラッグする(並び順が「カスタム」になる)。
2. `＋ 追加` で d と e を足して確定する。

- 一覧が **c, a, d, e** になり、並び順は「カスタム」のまま。

## 4. 改名した後

1. 何かルール(たとえば末尾に `_x`)を設定して実行する。
2. `＋ 追加` を押す。

- **改名後の名前**のファイルにチェックが付いている。

## 5. 選択モードとスクロール

1. 一覧の行を長押しして選択モードに入る → **`＋ 追加` が消え、folder 行の高さは変わらない**(一覧が跳ねない)。モードをやめる。
2. (ファイルが多ければ)一覧をスクロールする → folder 行は先頭に残る。

## 6. 「別フォルダへ」は今までどおり

1. 帯の「別フォルダへ」→「すべて」。

- browser は**保存場所から**始まり、前の選択は付いていない。閉じてよい。
