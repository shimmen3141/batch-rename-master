# 手動確認: 更新日時ずらしを歯車へ移す(Androidエミュレータ)

**対象buildは、`lib/`・`hook/`・`src/`の内容が commit `683e4ce` と同一のもの**である。branch `asdd/008-ui-alignment/T43-settings-gear-shift-toggle` のHEADからbuildすればこれを満たす。**code・dependency・build設定が変わったら、この結果は再利用しない。**

**Androidエミュレータで確認する**(`008:T39`で開発者が決めた方針)。見た目と操作を見るので debug build でよい。

## 使う端末と準備

- host側でworktree `.worktrees/008-T43-settings-gear-shift-toggle` へ`cd`してから`flutter pub get` → `flutter run`する(branchの移動は不要)。共通の手順は[`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md)。
- ファイルは`008:T25`のfixture(`Download/asdd-008-t25`の`a.txt` `b.txt` `c.txt`。改名後の名前でもよい)を使う。**無ければ**、[`008:T25`の手順書](../T25-dismissible-toast/manual-verification.md)の「準備するファイル」を実行する。
- 「ファイルを選ぶ」→「すべて」→ `Download` → `asdd-008-t25` で3件を選んで確定する。命名ルールは何か1つ設定しておく(空のままでもよいが、2.は設定した状態で見る)。

## 1. Androidでは歯車も切り替えも出ない

**こうなってほしい**

- 上の「**一括リネーム**」の帯の右端に**歯車は無い**。
- フッターに「**更新日時を一覧の並び順にずらす**」の**チェックボックスは無い**。フッターは**命名ルールのカードとリネームのボタンの2段**だけ。
- (以前はここにチェックボックスがあった。仕様ではAndroidでは出さない設定だった。)

## 2. 縦向き: 選択モードのフッター

1. 右上の**︙ →「外すファイルを選ぶ」**でモードに入る。

- フッターの大きさが入る前と**変わらない**。一覧の下端も動かない。
- 説明のカード(「選択したファイルをリネームリストから外します。」「**ファイルは削除されません。**」)が、さっきの命名ルールのカードと**同じ位置・同じ高さ**。「← 戻る」「0件を外す」がリネームのボタンと同じ位置・高さ。**フッターに不自然な空きが無い。**
- 1件選んで「1件を外す」→ 外れて通知が出る。「← 戻る」でモードを抜ける(`008:T42`と同じ)。

## 3. 横向き: 2ペインの選択モードのフッター

1. エミュレータを**横向き**にする(エミュレータの回転ボタン)。左に一覧、右にルールの2ペインになる。
2. 通常のフッター(一覧の下)はリネームのボタンだけであることを見る。
3. ︙ →「外すファイルを選ぶ」でモードに入る。

- フッターは**1段**: 左に説明(iのアイコンと小さな2行「選択したファイルをリネームリストから外します。」「ファイルは削除されません。」)、右に「← 戻る」「0件を外す」。
- 説明が**読める大きさ**で、ボタンと重ならず、はみ出さない。フッターの大きさはモードの出入りで変わらない。
- 終わったら縦向きに戻す。

(横向きが2ペインにならない端末(幅が840dp未満)なら、3.は「未確認(端末が狭い)」と書いてほしい。)

## 4. (任意)Windowsで歯車を見る

エミュレータでは歯車が出ないので、**できる場合だけ**hostで`flutter run -d windows`する。行わなくてよい(振る舞いはtestで確かめている)。

- ヘッダーの右端に**歯車**がある。押すとメニューに「**更新日時を一覧の並び順にずらす**」(チェック無し)が出る。
- 選ぶとメニューが閉じる。もう一度開くと**チェックが付いている**。もう一度選ぶと外れる。
- ONのとき、ヘッダーやフッターに印は出ない(決定どおり)。
- フッターにチェックボックスは無い。
