# T31: 長押しドラッグ選択の実機確認

対象は Android 実機です。指の長押し、画面端での保持、慣性のない連続スクロールは
emulator のポインタ操作だけでは受け入れ証拠にしません。共通の起動手順は
[`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md)
を使います。

## 準備

- この task の対象 commit で Android 実機へ build する。
- 名前が `a.txt`、`b.txt`、`c.txt` を含み、合計 12 件以上ある一覧を読み込む。
  可能なら少なくとも 2 件を別フォルダから加え、場所表示の有無が混ざる一覧にする。

## 確認項目

| 操作 | 期待結果 |
| --- | --- |
| 通常表示で `a → b → c → b` の順に、a の行を長押しして指を離さずに通る | 選択は a と b。c は選択から戻る。並び順と一覧件数は変わらない。 |
| ケバブから選択モードへ入り a を選んだ後、b を長押しして `b → c → b` と通る | 先に選んだ a は残り、b は選択、c は選択から戻る。 |
| 12 件以上の一覧で行を長押しして選択し、指を下端（次に上端でも）へ寄せて保持する | 一覧が端方向へ連続スクロールし、指の下を新しく通る実在行が選択される。行高や場所表示が混ざっても飛ばした行・存在しない候補は生じない。 |
| 上の端スクロール中に指を端から中央へ戻す、指を離す、キャンセルする。先頭/末尾まで保持する | それぞれ選択追跡とスクロールが止まる。先頭/末尾を越えて空白へ scroll せず、候補数は実在行数を越えない。 |
| 通常表示で長押しせず行をドラッグする | 選択モードへ入らず、候補も作らない。 |
| 通常表示で右端の並び替えつまみを長押しして移動する | 既存の並び替えは行える。選択モードは開かない。 |

結果は対象 commit、端末名/Android 版、各項目の PASS/FAIL と再現手順を task.md に記録する。
