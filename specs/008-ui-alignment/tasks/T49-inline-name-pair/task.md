# T49 変更前後の名前が1行に収まるなら横に並べる

## 目的

変更前の名前と変更後の名前を**横に並べても1行に収まる行では1行にまとめ**、一覧に入る行数を増やす。収まらない行は今のまま縦に積む。

## 出所

開発者の要望(2026-10-01、原文): 「変更前後の名前が横に並べても1行に収まるなら1行にまとめる・各行の警告の出し方を再調整するの二つも改めてタスクとして登録したいです。」(前半)

## 範囲(着手時に詰める)

- 判定は**行ごと**か**一覧全体で揃える**か。行ごとだと行の高さと名前の開始位置がばらつく。どちらにするかは着手時に開発者へ選択肢を出す。
- 収まるかどうかは、実際の文字の幅(文字倍率を含む)で測る。省略(`…`)が出るなら「収まらない」とする。
- `008:T10` で決めた強弱(変更前は小さく薄く、変更後は太字)と矢印の読み方を保つ。
- 行の警告(上の行に右寄せ)、補足情報(`T48` のサイズを含む)との並びを崩さない。
