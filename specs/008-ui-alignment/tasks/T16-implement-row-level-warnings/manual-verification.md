## 手順

各手順の先頭でルールを作り直してください。**前の手順のルールが残っていると後半が
成立しません。**

### 手順1 — 行の警告が読める(重複)

1. アプリを起動し、`DCIM/t07-fixtures` を読み込みます。**全選択**にします。
2. 下部のルール設定ボタンを押し、トークンを**「固定文字」1つだけ**にします。値は `photo`。
   シートを閉じます。

- **確認A**: **`.png` の行**の変更後名のすぐ下に **`名前が重複`** と出る。**タップも展開も
  していない状態で**読める。
- **確認B**: ヘッダに **`24 件の問題`** と出る。
- **確認C**: 文字が途中で切れて種別が読めない行が無い。

> **なぜ24件か**: fixtureは`.png` 24枚 + `.jpg` / `.txt` / `.pdf` 各1です。変更後名は
> 拡張子を保つので、重複するのは`photo.png`の24枚だけです。**他の3件に警告が出ないのは
> 正しい動きです。**

### 手順2 — 原因が複数あっても一覧が覆われない(N-9)

1. ルールを作り直します。**「連番」(桁数1、開始100)** と **「日時」(作成日時)** の
   2つにします。シートを閉じます。

- **確認A**: 下部のルール設定ボタンの**「命名ルール」の右**に、**`桁不足`** と
  **`基準日時なし`** が赤く出る(2つとも)。
- **確認B**: **ファイル一覧が画面の大半を占めたままである。** 警告の表示が一覧の見える
  範囲の半分以上を覆っていない。
  → **これが`T07`で不成立だった点です**(2026-08-29に開いた帯が一覧の半分以上を覆った)。
- **確認C**: ルール設定ボタンが**2行**になっている(上に「命名ルール」、下に設定中の
  ルール、右端に「編集」)。
- **確認D**: 日時トークンを**もう2つ**足して原因を増やします(合計4つ)。
  **警告の表示は増えません** — `桁不足` と `基準日時なし` の2つのままです。
  **一覧の高さも変わりません。**

### 手順3 — 文字サイズを最大にする

1. 端末の**設定 → ディスプレイ → フォントサイズ**(または「表示サイズとテキスト」)を
   **最大**にします。アプリに戻ります。

- **確認A**: ヘッダの **数字が読める**(`27 / 27 件を選択` の両方の数字と、
  件数表示の数字)。語尾(`件を選択` の `選択` など)が切れるのは**想定内**です。
- **確認B**: ルール設定ボタンの **`桁不足`** と **`基準日時なし`** が**両方読める**。
- **確認C**: **文字が枠の外へはみ出していない**(オレンジと黒の縞が出ていない)。
- **確認D**: 一覧が完全に潰れていない(行が1つ以上見える)。

> **既知**: この端末の設定が「最大」でも、Androidのfont scaleは通常2.0までです。
> それ以上(3.0相当)では一覧がかなり狭くなることを把握しており、`T10` が引き受けて
> います。**ここで見たいのは「読めるか・はみ出さないか」です。**

2. 確認したらフォントサイズを**既定へ戻します**。

### 手順4 — 詳細が両方から開く

1. ルールを手順2のまま(または連番+日時)にします。

- **確認A**: **ヘッダの件数表示**(`N 件の問題`)を押すと、ダイアログが開く。
- **確認B**: ダイアログの中に **「ルールの問題」** という見出しがあり、その下に
  **`1 番目のトークン(連番 1 桁)は 3 桁必要です`** のような**トークンを名指しした説明**が
  並ぶ。**説明はトークン1本につき1つ**で、ファイルの件数ぶん繰り返されていない。
- **確認C**: さらに下に **`基準日時なし N 件`** のような**種別ごとの見出しと、ファイルを
  名指しした一覧**がある。
- **確認D**: 閉じて、今度は**行の警告の文字**を押す。**同じダイアログ**が開く
  (その行のぶんだけに絞られていない)。
- **確認E**: 行の警告が**押しやすい**。何度も外さないと押せない、ということが無い。

### 手順5 — ルール未設定

1. ルール設定シートを開き、トークンを**すべて削除**します。シートを閉じます。

- **確認A**: 行に警告が**出ない**。
- **確認B**: ヘッダに件数が**出ない**(`問題なし` も出ない)。
- **確認C**: ルール設定ボタンに `桁不足` などの種別が**出ない**。
- **確認D**: 「命名ルールが未設定です」に相当する**案内**が出る。
- **確認E**: ルール設定ボタンが**主役の表示**(`変更する名前を設定する`)へ入れ替わる。
- **確認F**: トークンを1つ足すと、案内が消えて警告の提示に戻る。
