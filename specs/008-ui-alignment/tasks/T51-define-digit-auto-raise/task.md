# T51 件数が増えたとき連番の桁数を自動で引き上げる振る舞いを定義する

## 目的

一覧の件数が増えて、ゼロ埋めありの連番の桁数が下限(003 REQ-014)を下回ったときに、**ルールの桁数を下限まで自動で引き上げ、引き上げたことを利用者へ知らせる**振る舞いを 003 spec へ書き、承認を得る。実装は `T52`。

## 出所

`T50`(行の警告の再調整)の検討で開発者が出した案(2026-10-01、原文): 「連番の桁不足については、現状では後からファイルを追加する場合でしか出ないと思いますが、このときに自動で連番の桁を増やしつつトーストで通知すれば、ユーザが知らない間に変更されるという事態が起こらないと思いました。」

Agent の推奨(件数が減っても戻さない・保存するルールにも残す)を含め、開発者は「推奨案1~4で進めてください。仕様変更は承認します。」と答えた。

## 衝突する正本

- **2026-09-29 の決定(`T21`)**: 「件数が後から増えて下限を超えたとき: 警告を残す。ルールを黙って書き換えない」。003 の代表例15。**この決定を変える。** 「黙って」を通知で解消するので、決定の趣旨(利用者が知らない間に変わらない)とは両立する。
- 001 の桁不足の判定(REQ-008)と実行時の自動拡張(REQ-011)は**変えない**(008 plan の方針「判定は動かさない」)。引き上げ後は判定が桁不足を返さなくなるだけである。
