## 手順と期待結果

1. 写真を数件読み込み、ルールを入れて変更後の名前が出る状態にする。
   - 変更前の名前と `→` が白に近い色(本文の色)。変更前の名前は今までどおり小さく、太字ではない。変更後の名前は緑の太字のまま。
2. 補足情報(日時・大きさ)を見る。
   - 補足情報の左に灰色の太めの縦線があり、補足情報の行にだけかかる(名前の2段にはかからない)。面は塗られていない。
   - 縦線の太さ・色・文字との間が、強調せずにまとまりに見えるか。**調整したい点があれば値を伝えてほしい**(今は太さ 3dp、補足情報の文字と同じ灰、間 6dp)。
3. 別のフォルダの写真も読み込み、場所が出る状態にする。並び順を作成日時にする。
   - 場所と日時の2行とも縦線の内側にある。
4. 警告の出る行(例: 2件が同じ名前になるルール)を作る。
   - 赤いのは変更後の名前と右端の警告だけで、変更前の名前は白に近い色のまま。
5. 行を長押しして選択モードにする。
   - 選ばれた行(面が染まる)でも縦線が見える。
6. (attempt 2)補足情報の字下げと大きさの書き方を見る。
   - 補足情報が縦線ごと、名前の左端(`→`)から少し右へ下がっている(4dp)。
   - 大きさが有効数字3桁で出る(例: `2.40 MB`、`12.3 MB`、`0.98 GB`)。`1023.0 MB` のような書き方は出ない。
   - app 内の browser(ファイル選択)の行の2行目の大きさも同じ書き方になっている。
