対象 commit・build は実装後に書く。共通の起動手順は [`docs/development/emulator-verification.md`](../../../../docs/development/emulator-verification.md)。

## 手順と期待結果(実装後に具体化する)

1. 変更前(`dev`)で、ファイルを十数件読み込み、1画面に並ぶ行の数を数えてスクリーンショットを撮る。
2. この task の build で同じファイルを読み込む。
   - 補足情報(日時・大きさ。複数の場所なら場所も)が薄い面の帯に入り、名前の2段と分かれて見える。
   - 変更後の名前が少し大きい。
   - 1画面に並ぶ行の数を数え、1 と比べる。
3. 作成日時が無いファイルを作成日時のルールで読み込み、`作成日時: 不明` が赤で出る。
4. 選択モード(長押し)で選んだ行の色と、帯の色が見分けられる。並び替えのつまみを掴んだときも同じ。
