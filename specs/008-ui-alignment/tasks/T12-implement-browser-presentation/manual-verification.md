## 手順と期待

### 1. 入口(U1)

1. 「ファイルを選ぶ」→「すべて」を選ぶ。

**こうなってほしい(SDカードを挿していない端末)**

- **保存場所の一覧を挟まず、いきなり内部ストレージの中身(フォルダの一覧)が出る。**
- 画面の上の現在地が「**内部ストレージ**」になっている。
- 左上に**保存場所を選び直すボタン(SDカードの絵)が出ない**。**出ていなくて正しい**
  — 切り替え先が無いためで、004 specが自由としている範囲である。

**こうなってほしい(SDカードを挿している端末。無ければこの節はskipしてよい)**

2. 「すべて」を選ぶと**保存場所の一覧**が出る。「内部ストレージ」を選ぶ。
3. 一番上まで戻り、左上の**保存場所を選び直すボタン**を押す。
4. 「SD カード」を選ぶ。

- 手順3でbrowserは**閉じない**。一覧へ戻るだけである。
- 手順4でSDカードの中身が出る。

### 2. 近道(U2)

1. 内部ストレージの一番上(root)を見る。

**こうなってほしい**

- **★のついた行が1件も無い。**
- 「Download」「DCIM」「Pictures」などが、**フォルダの一覧の中に1回だけ**並ぶ。
  **同じ名前が上と下に2回出ない。**

### 3. 上へ戻る矢印(U3)

1. 適当なフォルダへ入る。

**こうなってほしい**

- 左上の矢印が **`←`**(左向き)になっている。押すと1つ上のフォルダへ戻る。
- 一番上まで戻ると矢印が消える(それより上へは行けない)。

### 4. 空のフォルダ(U6)

1. 中身が何も無いフォルダを作って入る(PowerShellの準備に `New-Item -ItemType Directory 空フォルダ` を足してよい)。

**こうなってほしい**

- **「このフォルダにファイルはありません」**と出る。**何も無い画面にならない。**
- 読めないフォルダ(004 REQ-018の注記が出る場所のうち、開くこと自体に失敗するもの)では、これとは**別の文言**(「このフォルダを開けませんでした」)が出る。

### 5. 壊れていないこと(T37の回帰)

1. fileを長押ししたままdragして複数選ぶ。
2. 「すべて選択」を押す。
3. フォルダを移動する。

- 1・2は`T37`のときと同じように動く。
- 3で選択が解除される。
- 選んで「確定」すると、その2件だけがリネーム画面のリストに入る。
