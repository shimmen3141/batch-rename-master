# 手動確認: 選択と除去の導線

## 何を確かめてほしいか

`008 / T04` で、**行の checkbox を廃止**しました(2026-09-18 に承認いただいた 002 REQ-016)。
一覧にあるファイルはすべて rename 対象で、外すのは**行の ×** だけです。誤って外したときは
**直後に取り消せます**(REQ-017)。読み込み帯の `すべて外す` は **`一覧を空にする`** になりました。

自動testが押さえているもの(checkbox が無いこと、取り消しで元の位置へ戻ること、占有名が戻ること、
何も外れていないときは通知が出ないこと、狭幅でヘッダの数字が消えないこと)は**手順に入れていません**。
お願いするのは、**実機で押しやすいか・通知が見えるか**だけです。

## 手順1 — 起動直後(1分)

デモデータ(9件・2フォルダ)のまま見ます。

- **確認A**: **行に checkbox が無い**。ヘッダに「全選択」の四角も無い。
- **確認B**: ヘッダが **`9 件`** になっている(「9 / 9 件を選択」ではない)。
- **確認C**: 行が窮屈になっていない。checkbox が無くなったぶん、名前とサブ情報の取り分が増えている。

## 手順2 — 1件外して戻す(2分)

> **2回目の依頼(2026-09-18)はここだけです。** 1回目は demo data が元場所ハンドルを持たず
> **× が出ませんでした**(手順1・3・4 は `c7cf22b` で成立済み)。ハンドルを持たせたので、
> 行の右端に × が出ます。**確認Bの `9 件` と確認Cの見た目も、ついでに見てください** —
> demo data を触ったためです。


- **確認D**: 行の右端の **×** が**押しやすい**。狙いを外して行そのものや警告が反応しない。
- **確認E**: 押すと行が消え、**下から通知**が出る(`1 件を一覧から外しました` と `元に戻す`)。
- **確認F**: 通知が**下部バー(リネームbutton)に隠れていない**。読めて、`元に戻す` を押せる。
- **確認G**: `元に戻す` を押すと、外した行が**元の位置**に戻る(末尾ではない)。
- **確認H**: 連番のルールを設定していれば、外している間は**番号が詰まり**、戻すと元に戻る。

## 手順3 — 一覧を空にして戻す(1分)

- **確認I**: 読み込み帯の button が **`一覧を空にする`** になっている(`すべて外す` ではない)。
- **確認J**: 押すと一覧が空になり、通知から **`元に戻す`** で**並びのまま**戻る。
